# Подключение Firebase к «Мой ритм»

Текущая версия приложения продолжает сохранять данные локально. Облачная синхронизация ещё НЕ включена.

1. Настроить в Firebase Authentication Authorized domains: домен сайта GitHub Pages (если разрешён для проекта).
2. Опубликовать firestore.rules в Firebase Console → Firestore → Rules. До этого НЕ включать облачные записи.
3. Получить полный Web app firebaseConfig из Firebase Console → Project settings → Your apps. apiKey не является секретом, но private key / service account никогда не добавлять в репозиторий.
4. Подключить firebase-sync.js к приложению и реализовать явный вход Google.
5. Для первой синхронизации сравнить локальную и облачную версии и запросить выбор, не перезаписывать одну другой молча.
6. Проверить запись одной тестовой записи, повторный вход, чтение на втором устройстве и запрет чтения из чужого аккаунта.
7. Только после теста включать автоматическую синхронизацию. Не писать «Сохранено в облаке» до успешного ответа Firestore.

Ограничения: GitHub Pages не выполняет серверный код. Для фоновых push понадобится отдельный отправитель. Firebase Cloud Messaging не означает автоматическую отправку уведомлений без сервера.
